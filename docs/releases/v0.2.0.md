# zsh-glint 0.2.0 — A little light on your command line

This release improves project presentation, diagnostics, and lookup performance while keeping the runtime native to Zsh and offline.

- **A clearer first look:** a microglint visual identity, real terminal demo, still image, and separate English/Chinese homepages.
- **Explain what is wrong:** `zsh-glint doctor` checks configuration, hooks, widgets, and native completion without printing history contents or changing configuration.
- **Measured lookup improvements:** native array search plus an invalidated query cache. The included macOS arm64 / Zsh 5.9 benchmark measured a 1,000-candidate cold miss at 0.10 ms median, down from 2.21 ms. This excludes startup/rendering and is not a latency guarantee.
- **Safer loading:** local option/alias scope and protection against recursive wrapper chains after another plugin replaces a widget.
- **Ready for contributions:** benchmark scripts, compatibility notes, issue templates, and contribution instructions.

## Install or update

```sh
git clone --branch v0.2.0 https://github.com/carefreelove/zsh-glint.git
cd zsh-glint
zsh scripts/install.zsh
```

Open a new Zsh session. Requires Zsh 5.9+ on macOS or Linux. For an existing checkout on `main`, use `git pull --ff-only`, then reopen Zsh. Keep the entire project directory, including `lib/`, in place.

Existing `TC_*` settings and `terminal-completion` compatibility entry points remain supported. If another plugin retained a glint forward-widget wrapper, reopen Zsh before loading glint again. Other inline suggestion providers may conflict; use one at a time.
